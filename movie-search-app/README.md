# 🎬 Movie Search App

A responsive Movie Search App built as part of my **CodeVedX Frontend Development Internship**.

The application uses the **TMDB API** to search for movies, display movie information and ratings, view detailed movie information, and save favorite movies.

## 🚀 Live Demo

Coming soon...

## ✨ Features

- 🔍 Search for movies using the TMDB API
- 🎬 Display movie posters and titles
- ⭐ Display movie ratings
- 📄 View detailed movie information
- ❤️ Add movies to Favorites
- 🗑️ Remove movies from Favorites
- 💾 Store Favorites using Local Storage
- 🧭 Navigation using React Router
- ⏳ Loading states
- ❌ Error handling
- 🔎 No-results handling
- 📱 Responsive design
- 🌑 Dark-themed user interface
- 🏷️ TMDB API attribution

## 🛠️ Technologies Used

- HTML
- CSS
- Tailwind CSS
- JavaScript
- React.js
- React Router
- TMDB API
- Vite
- Local Storage
