# CodeVedX Admin Dashboard

A responsive admin dashboard built for the CodeVedX Frontend Development task.

## Features

- Responsive dashboard layout with a collapsible mobile sidebar
- Analytics cards for revenue, orders, customers, and conversion rate
- Interactive revenue/orders area chart using Recharts
- Revenue chart period selector and traffic source donut chart
- User table with search and status filters
- Add users through a form and remove users from the demo table
- Export the currently filtered user list to CSV
- Notifications popover, section navigation, and toast feedback
- Responsive layouts for desktop, tablet, and mobile screens
- Accessible labels on common controls and empty search state

## Tech stack

- React + Vite
- Tailwind CSS v4 (Vite plugin and CSS import)
- Recharts
- Lucide React icons
- Plain CSS for detailed layout and responsive styling
